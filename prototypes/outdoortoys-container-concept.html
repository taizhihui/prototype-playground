Agent Concept

From trigger logic
to goal-driven engagement

Today, AI Journey runs flows and campaigns as separate pre-configured sequences. A marketer sets a trigger. A sequence fires. A message goes out.

The agent model inverts this. A marketer confirms targets and guardrails. The agent evaluates every shopper, every incoming signal, and decides in real time — who to engage, when, and with what message.

Today
Cart abandon flow fires when a cart is abandoned — regardless of what else is happening with the shopper.
Campaign blasts everyone in the segment at the scheduled send time — with no awareness of what flows are already running for that shopper.
Flows and campaigns run independently — a shopper can get a cart recovery and a campaign blast in the same day for different products.
Marketer configures a trigger and sequence for each flow type.
Lifecycle programs ship as separate flows you set up and switch on — a stage without a flow gets nothing.
Agent
Agent evaluates all active signals for each shopper and decides which to pursue — or whether to wait.
Campaign always reaches the full eligible segment. Agent personalizes each message and suppresses conflicting flows during the campaign window.
Campaign always wins during its window. Flows hold and re-evaluate after. No shopper gets a flow message while a campaign is active.
Marketer states a goal once. AI handles execution per shopper, per signal.
Every shopper is always in exactly one lifecycle state, and every state is covered. The merchant confirms a target per state; the agent never misses a window.

Here's what that looks like in practice — Outdoor Toys as the worked example.

Campaign Intent
Worth sending?
Per-shopper send check — every campaign
A sale is an incentive. A product drop opens new demand. Before a campaign reaches a shopper, the agent checks its intent against the person: relevant to what they own and browse · right lifecycle moment · no open CX issue. When the answer is no, that shopper is skipped.
Suppression Logic
5 conditions
When the agent holds — in any state
Active campaign window · Active conversation open · Support ticket unresolved · Message sent within 7 days · Shopper replied "not now" within 48h. The agent holds and re-evaluates on the next signal — it does not skip.
Signal Hierarchy
SA › Cart › Browse
Intent ranking — in any state
When multiple signals are active, the agent leads with the highest-intent one. A Shopping Assistant session outranks a cart abandon — the purchase blocker is already resolved and the context is in hand.
Guardrails · set by Outdoor Toys
Frequency Max 2 messages per shopper per week
Discounts Up to 10% outside active sales · sale pricing during campaign windows
Quiet hours No messages 9pm–9am UK
